# Technologies that we plan to use for web programming
HTML5 for the page structure and semantic elements.

CSS in a dedicated stylesheet (style.css) for all styling. We will ensure that SVG elements are styled with selectors and avoid inline styling.

Vanilla JavaScript for logic and interactivity, without heavy frameworks, to keep the website simple and lightweight.

D3.js to load the data and draw the data visualizations as SVGs.

Git and GitHub Pages for version control and deploying the website.

# Data handling and processing
Python with pandas to clean, filter, and aggregate the raw datasets (leveraging our existing Python skills).

Jupyter Notebooks to document each step of the data manipulation process, ensuring that our data processing is fully reproducible.

The processed data will be exported as CSV or JSON files, stored in the repository, and loaded asynchronously into our charts using D3.js.
